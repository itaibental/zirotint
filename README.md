# הכל בכף היד · לומדת תקשורת וחברה לבגרות

לומדה אינטראקטיבית (כרטיסיות שיעור + שאלונים + לוח מורה) לבחינת הבגרות בתקשורת וחברה.
הפרויקט בנוי כאתר סטטי טהור (HTML/CSS/JS מודולרי, ES Modules) - **בלי שלב build**,
כך שאפשר להעלות אותו כמו שהוא ל-GitHub Pages ולהריץ אותו ישירות בדפדפן.

## מה יש בלומדה

- **76 מושגים** מסודרים ב-9 זירות: זירת העל (19), זירה 1 · מציאות תקשורתית (8),
  זירה 2 · גלובליזציה (8), זירה 3 · חדשות וצילום (15), זירה 4 · הומור וסאטירה (5),
  זירה 5 · פרסום ושיווק (5), זירה 6 · קולנוע וטלוויזיה (5), זירה 7 · ספורט (5),
  זירה 8 · רשתות חברתיות (6).
- **בקרת גודל טקסט לשיעור ולשאלון בלבד** - סקאלה (סליידר) בראש הדף שמגדילה/מקטינה
  את הטקסט רק בתוך מסך השיעור ומסך השאלון (5 רמות, 85%–145%), ואינה משפיעה על
  התפריט הראשי, עמוד הבית או אזור המורה. הבחירה נשמרת בזיכרון הדפדפן.
- **כפתור מעבר ידני בין תצוגת נייד לתצוגת מחשב** - עוקף את הזיהוי האוטומטי לפי
  רוחב המסך, כדי שאפשר לכפות תצוגה מסוימת בכל מכשיר.
- **מסך מובייל ממורכז ללא גלישה אופקית** - טקסט ותוכן לעולם לא "בורחים" הצידה.
- **תצוגת דסקטופ מותאמת** - מיכל תוכן רחב יותר וטיפוגרפיה גדולה יותר במסכים רחבים (1024px+).
- **מנגנון השהיית קריאה** בשקפי השיעור - 30 שניות + חובת נגיעה בטקסט לפני מעבר לעמוד הבא.
- **עמוד בית לפי זירות** - משבצות לחיצות, כל אחת פותחת את המושגים שבזירה שלה.
- **חיפוש גלובלי** בראש הדף - זמין מכל מסך, מציג תוצאות חיות ומעביר ישירות לשיעור הרלוונטי.
- שיעור בכרטיסיות + שאלון עם רמזים ומשוב + לוח מורה עם ציונים וסנכרון ענן אופציונלי.

## מבנה הפרויקט

```
index.html                     # קובץ ה-HTML הראשי (מבנה הדפים בלבד, בלי לוגיקה)
css/
  styles.css                   # עיצוב מותאם אישית (מעבר ל-Tailwind CDN)
js/
  app.js                       # הלוגיקה הראשית: ניווט, שיעור, שאלון, לוח מורה
  audio.js                     # אפקטי סאונד (Web Audio API)
  cloud.js                     # סנכרון ענן אופציונלי מול Firebase
  data/
    modules-index.js           # מרכז את כל המושגים למערך אחד (learningModules)
    initial-submissions.js     # שורות דמו שמופיעות בלוח המורה בהתחלה
    concepts/
      fiske.js                 # מושג אחד = קובץ אחד
      globalization.js
      democracy.js
      ... (קובץ לכל מושג, 24 בסך הכל)
```

## איך זה עובד

`index.html` טוען את `js/app.js` כ-`<script type="module">`. המודול הזה מייבא (`import`)
את מערך המושגים מתוך `js/data/modules-index.js`, שבתורו מייבא כל קובץ מושג בנפרד
מתוך `js/data/concepts/`. כך כל מושג הוא קובץ עצמאי, קטן וקל לעריכה, בלי לגעת בשאר הקוד.

## הוספת מושג חדש

1. העתיקו קובץ קיים מ-`js/data/concepts/` (למשל `democracy.js`) לקובץ חדש עם שם המושג
   (למשל `bias_new.js`), ועדכנו את השדות: `id`, `title`, `arena`, `shortDesc`, `slides`, `questions`.
   כל `id` חייב להיות ייחודי (אותיות אנגליות/מקף תחתון, ללא רווחים).
2. פתחו את `js/data/modules-index.js` והוסיפו שורת `import` אחת + שורה אחת במערך המיוצא, למשל:
   ```js
   import bias_new from './concepts/bias_new.js';
   // ...
   export const learningModules = [
     // ... מושגים קיימים
     bias_new,
   ];
   ```
3. זהו - המושג יופיע אוטומטית במשבצת הזירה המתאימה בעמוד הבית (או במשבצת חדשה אם זו זירה
   חדשה שלא הייתה קיימת), בטאבים ובחיפוש הגלובלי. סדר הזירות בעמוד הבית ובקובץ נקבע לפי
   הפונקציה `arenaRank` / `arenaOrder` (זירת העל תחילה, ואז זירה 1, 2, 3...).

אפשר גם להוסיף מושג ישירות דרך "אזור המורה" > "מחולל לומדה ושאלון חדש" בממשק עצמו
(נוסף בזיכרון הדפדפן בלבד, לא נשמר לקובץ).

## הרצה מקומית

מודולי ES דורשים הגשה דרך שרת HTTP (לא ניתן לפתוח את `index.html` ישירות מהדיסק
עם לחיצה כפולה, בגלל מדיניות CORS של הדפדפן על `file://`). לדוגמה:

```bash
npx serve .
# או
python3 -m http.server 8000
```

ואז גשו לכתובת שמודפסת בטרמינל (למשל `http://localhost:8000`).

## פרסום ב-GitHub Pages

1. העלו את כל התיקייה (עם המבנה שלה) לריפו ב-GitHub.
2. Settings → Pages → Source: הענף הרלוונטי, תיקיית `/root`.
3. האתר יהיה זמין בכתובת שמוצגת שם תוך דקה-שתיים.

## סנכרון ענן (אופציונלי)

לחיצה על "סנכרון ענן" בראש העמוד פותחת חלון להדבקת אובייקט קונפיגורציה של Firebase.
בלי זה, כל הציונים נשמרים רק בזיכרון הדפדפן (נעלמים ברענון) - זה בסדר גמור לשימוש הדגמה/כיתה בודדת.
